# Навык: Эксперт по Python (Python Expert Skill)

Этот навык содержит правила и лучшие практики при написании кода на Python.

## Основные принципы:
1. **Строгая типизация**: всегда используй `type hints` (`from typing import Optional, List, Dict, Any, Union`).
2. **Асинхронность**: для ввода-вывода и сетевых запросов используй `asyncio`, `httpx` или `aiofiles`.
3. **Обработка исключений**: всегда перехватывай конкретные исключения, логируй ошибки и избегай "голых" `except: pass`.
4. **Форматирование**: придерживайся стандартов PEP 8, используй осмысленные имена функций и классов.
5. **Безопасность путей**: на Windows всегда используй `os.path.join` или `pathlib.Path` для кросс-платформенности.
